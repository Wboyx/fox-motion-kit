# مسیر ریگ دوبعدی

مناسب برای: حرف‌زدن، واکنش کوتاه، تیکه‌های تکرارشونده ولاگ.

## چرا این مسیر برای ولاگ بهتر است

```text
یک بار ریگ، بی‌نهایت انیمیشن
هویت هرگز نمی‌پرد، چون همان تصویر تأییدشده حرکت می‌کند
هزینه هر کلیپ صفر
اجرای محلی، بدون وابستگی به سرویس بیرونی
```

## زنجیره کار

```text
شیت تأییدشده
   ↓
جدا کردن پس‌زمینه
   ↓
تجزیه به لایه‌ها (مو، چشم، دهان، بدن، اکسسوری)
   ↓
ریگ: مش و پارامتر برای هر لایه
   ↓
انیمیشن: چشمک، تنفس، حرکت سر، دهان
   ↓
رندر کلیپ و تحویل به تدوین
```

## نکته‌های عملی

```text
۱. لایه‌ها باید از تصویر تمام‌رخ گرفته شوند، نه از پنل کوچک شیت
۲. ناحیه‌های پنهان پشت مو و لباس باید پر شوند، وگرنه هنگام حرکت سوراخ می‌شود
۳. اول فقط سه پارامتر: پلک، دهان، چرخش سر. بقیه بعداً
۴. حرکت طبیعی از دامنه کم می‌آید، نه از دامنه زیاد
۵. برای صحبت، دهان را با صدا همگام کن، نه با حدس
```

## ابزارها

دو خانواده وجود دارد:

```text
تجاری  ابزارهای استاندارد ریگ دوبعدی و وی‌تیوبر
متن‌باز ابزارهای تجزیه خودکار لایه و ریگ سریع
```

قبل از انتخاب، این سه را بسنج:

```text
□ آیا از محیط تو در دسترس است
□ آیا خروجی ویدیویی می‌دهد یا فقط زنده اجرا می‌شود
□ آیا فایل پروژه قابل ویرایش بعدی است
```

## دروازه پذیرش ریگ

```text
□ چشمک طبیعی است، نه مکانیکی
□ دهان با صدا هماهنگ است
□ مو هنگام حرکت سر پاره نمی‌شود
□ عینک و اکسسوری با صورت جابه‌جا می‌شوند
□ صورت در حرکت، همان صورت شیت است
```
